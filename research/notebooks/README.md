# 📓 Directory: `research/notebooks`

Folder ini dikhususkan untuk pengolahan dan visualisasi data:
- Menggunakan Jupyter Notebook (`.ipynb`) dengan library Python seperti **Polars**, **NumPy**, **Plotly**, atau **Matplotlib**.
- Menggunakan **Evcxr Jupyter Kernel** untuk mengeksekusi kode Rust interaktif.

## Cara Menggunakan Environment Python
```bash
# Buat virtual environment lokal jika diperlukan
python -m venv .venv
source .venv/bin/activate
pip install polars pandas jupyter matplotlib plotly
jupyter lab
```
