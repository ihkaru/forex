# 🔬 Directory: `research` (Quantitative & Strategy Lab)

Laboratorium riset kuantitatif, formulasi strategi trading Forex, eksplorasi data matematis, dan dokumentasi backtesting.

## Struktur Sub-Direktori
- `notes/`: Dokumen konsep strategi, aturan entry/exit, formula indikator, dan catatan SMC/ICT/Price Action.
- `notebooks/`: File Jupyter Notebook (`.ipynb`), script analisis Python (Polars / Pandas), atau Evcxr (Rust Interactive Notebooks) untuk eksplorasi data historis.
- `backtests/`: Output laporan performa, file parameter genetik/optimasi, kurva ekuitas, dan metrik drawdown.
