# 📈 Directory: `research/backtests`

Folder untuk menyimpan data set backtesting dan hasil analisis statistik performa strategi.

## Struktur Isi:
- `data/`: Sample file tick dan candlestick format `.parquet` atau `.csv`.
- `results/`: Laporan JSON/HTML dari simulasi `apps/cli` atau `crates/core/application/src/services/backtest.rs`.
- `logs/`: Catatan trade log setiap simulasi (Win Rate, Profit Factor, Max Drawdown, Sharpe Ratio).
