# 🛠️ Directory: `scripts` (Automation & Maintenance Scripts)

Koleksi helper shell script untuk manajemen workspace, inisialisasi Git submodule, dan environment setup.

## Script:
- `setup_submodules.sh`: Menginisialisasi dan memperbarui seluruh Git submodule.
- `run_dev.sh`: Menjalankan daemon dalam mode local development.
