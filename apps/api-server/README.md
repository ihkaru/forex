# 🌐 App: `api-server`

Backend REST & WebSocket API yang melayani Web Frontend Dashboard.

## Endpoint Rencana:
- `GET /api/v1/signals` - Mengambil daftar sinyal aktif dan riwayat.
- `GET /api/v1/metrics` - Statistik win rate, profit factor, dan rasio R:R.
- `WS /ws/live` - Stream event sinyal dan tick harga secara real-time.
