# 🕷️ Crate: `scrapers` (Rewritten Scrapers to Pure Rust)

Direktori ini menampung modul penarik data (scrapers) yang di-reverse engineer dari repositori publik (Python/Node/Go) dan di-rewrite penuh ke bahasa **Rust**.

Setiap scraper di sini dirancang sebagai **Standalone Rust Crate (Submodule Ready)** sehingga Anda dapat mempublikasikannya sebagai open-source crate independen di GitHub jika diinginkan.

## Daftar Scrapers
- `forexfactory-rs/`: Scraper kalender ekonomi & high-impact news filter.
- `myfxbook-rs/`: Scraper community outlook & posisi ritel long/short.
- `investing-rs/`: Scraper berita makro dan indikator ekonomi global.
